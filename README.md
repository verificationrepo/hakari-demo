# hakari-demo

noteアカウント「はかり｜AI検品係」の記事で検品した、AI製ページの実物デモです。すべて検証用の架空のお店・サービスで、フォームはどこにも送信されません。

- `001-lp-saiten/` AIにLPを作らせて数字で検品してみた（2026-10）
- `002-ad-copy/` AIに広告文を書かせて事実と照合してみた（2026-10）
- `003-form/` AIに予約フォームを作らせて、届くか・失敗時の表示・安全面を試してみた（2026-10）。送信先の応答はデモ用に差し替え、外部へは送信しません
- `004-lp-gyoshu/` 業種を変えてAIにLPを18枚作らせ、点数と「AIが足した内容」を検品（2026-10）。掲載内容はAIの創作を含みます
