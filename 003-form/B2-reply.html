こむぎ堂さんの予約フォームを作りました（`index.html` の1ファイルです）。

## しくみ

自分でサーバーを用意しなくても予約がメールで届くように、**FormSubmit（フォームサブミット）** という無料サービスを使っています。お客様が「予約を送信する」を押すと、お名前・電話番号・受け取り日・時間帯・注文内容（個数と合計の目安）が、表の形のメールでお店に届きます。

- 費用：**0円**（アカウント登録もいりません）
- プログラミング：**いりません**。書きかえるのはメールアドレス1か所だけです

## お店の方がやること（最初の1回だけ）

1. **メールアドレスを書きかえる**
   `index.html` をメモ帳（Mac なら「テキストエディット」）で開き、上のほうにある
   `const SHOP_EMAIL = "shop@example.com";`
   の `shop@example.com` を、予約を受け取りたいメールアドレスに変えて保存します。

2. **インターネットに公開する（無料）**
   HTMLファイルは、パソコンに置いたままではお客様が開けません。おすすめは **Netlify Drop**（https://app.netlify.com/drop）です。
   - `index.html` を入れたフォルダを、ブラウザの画面にドラッグ＆ドロップするだけで公開されます
   - 表示されたURL（`https://〇〇〇.netlify.app` のような形）が予約ページのアドレスです
   - 無料のアカウントを作っておくと、ページが消えずに残り、あとで差しかえもできます

3. **自分でテスト送信する → 確認メールのボタンを押す**
   公開したページから一度テストで予約を送ってください。FormSubmit から「Activate Form」という英語の確認メールが届くので、その中のボタンを押します。**これを押すまでは予約が届きません。**
   その後、もう一度テスト送信して、メールが届けば準備完了です。

4. **URLをお客様に案内する**
   Instagram のプロフィール、LINE公式アカウント、お店のチラシ（QRコード）などに貼ってください。

## 商品や値段を変えたいとき

`index.html` の下のほうにある「商品リスト」の部分を書きかえます。

```
{ name: "メロンパン", price: 200 },
```

この1行が1商品です。行をまねして増やしたり、消したりできます。変更したら、Netlify Drop にもう一度ドラッグ＆ドロップで反映されます。

## 知っておいてほしい注意点

- **予約は「メールが届くだけ」です。** 自動で確定・在庫管理はしません。フォームにも「お店からの確認をもって確定」と書いてあるので、届いたらお電話などで確認する運用がおすすめです。売り切れ・定休日も自動では止まらないので、定休日の予約が来たらご連絡ください。
- **迷惑メールフォルダも確認してください。** 最初の数通は迷惑メールに入ることがあります。
- **お客様の名前と電話番号は、FormSubmit（海外の無料サービス）を経由してお店に届きます。** 小さなお店の予約受付でよく使われる方法ですが、気になる場合は、ページ内に「入力いただいた情報は予約の確認にのみ使用します」といった一文を足すと安心です。
- **メールアドレスはページのソースから見える状態です。** 気になる場合、確認ボタンを押したあとに FormSubmit から届くメールに「ランダムな文字列のアドレス」が書かれているので、それを `SHOP_EMAIL` に入れればメールアドレスを隠せます。
- 無料サービスなので、FormSubmit 側の仕様変更や停止の可能性はゼロではありません。月に一度くらい、自分でテスト送信して届くか確かめておくと安心です。
